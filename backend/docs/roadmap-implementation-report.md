# Развитие «Кадра» по идеям Suwayomi

Выполненные этапы дополняют [автопрогресс и историю](reading-progress-report.md). Для запуска Angular и Spring Boot используйте [основной README](../../README.md). Flyway применяет V15–V19 поверх V14.

| Возможность | Где открыть |
| --- | --- |
| Новые главы и непрочитанные выпуски | «Библиотека → Новые главы» |
| Вертикальное и постраничное чтение, ширина, RTL, клавиши и предзагрузка | «Настройки» в читалке. Значения устройства и тайтла сохраняются в браузере. |
| Импорт папки, ZIP или CBZ | «Обзор → Импорт комикса». Каждая операция импортирует одну главу. |

| Экспорт и импорт JSON | «Библиотека → Резервная копия» |

## Работа функций

- Лента использует существующую фоновую проверку глав и приоритет библиотечных тайтлов. Полный первый проход создаёт исходный набор выпусков. Повтор известного ключа глава/перевод не создаёт события. Прочитанность и время обнаружения берутся отдельно от даты публикации.
- Локальные главы хранятся в `KADR_LOCAL_COMICS_DIR` (по умолчанию `backend/data/local-comics` при запуске из backend). Для импорта с сервера укажите `KADR_LOCAL_IMPORT_DIR`; форма принимает только путь внутри этой папки. ZIP/CBZ и папки поддерживают JPEG, PNG и GIF, до 1 000 файлов, 20 МиБ на страницу и 256 МиБ на главу. Архивные пути не используются как пути назначения. Идентичность повторного импорта определяется нормализованным названием тайтла, языком и содержимым страниц в естественном порядке.
- Перенос копирует статус, заметку и членство в секциях. При единственном совпадении по тому, номеру и языку добавляется позиция с первой страницы выпуска. Предпросмотр требует подтверждения. Исходная запись и существующая позиция назначения сохраняются. Пакетный API возвращает результат для каждого перевода, а интерфейс оставляет неудачные элементы выбранными.
- Загрузка Pepper&Carrot сохраняет контрольную сумму каждой страницы. Повтор и возобновление используют проверенные файлы при том же манифесте. В разделе «Скачанное» доступны пауза, возобновление и повышение приоритета. Прерванная активная задача вновь попадает в очередь после старта сервера.
- Версия JSON — 1. Резервная копия содержит тайтлы, позиции, историю, прочитанность, закладки, записи и секции библиотеки. Экспорт из интерфейса добавляет настройки читалки текущего браузера. Существующие записи и настройки имеют приоритет при импорте. Скачанные изображения, импортированные архивы и состояние внешних источников следует сохранять отдельной копией соответствующих папок и данных.

## Прототип на Suwayomi

Проверена официальная сборка [v2.4.2373](https://github.com/Suwayomi/Suwayomi-Server/releases/tag/v2.4.2373) с опубликованной SHA-256. Для запуска используйте Java 21 и постоянную папку Suwayomi. Из каталога backend, подставив путь к JAR:

~~~powershell
java '-Dsuwayomi.tachidesk.config.server.rootDir=./data/suwayomi' `
     '-Dsuwayomi.tachidesk.config.server.ip=127.0.0.1' `
     '-Dsuwayomi.tachidesk.config.server.port=4567' `
     -jar 'ПУТЬ_К_ОФИЦИАЛЬНОМУ_JAR'
~~~

В Suwayomi добавьте официальный магазин [Keiyoushi](https://keiyoushi.github.io/docs/guides/getting-started) и установите Pepper&Carrot 1.6.1. В окне запуска Spring Boot, вместе с существующими настройками PostgreSQL:

~~~powershell
$env:KADR_SUWAYOMI_ENABLED='true'
$env:KADR_SUWAYOMI_URL='http://127.0.0.1:4567'
$env:KADR_SUWAYOMI_INSTANCE='kadr-dev'
$env:KADR_SUWAYOMI_SOURCE='279282683217001983'
$env:KADR_SUWAYOMI_LANGUAGE='en'
~~~

Для BASIC_AUTH задайте `KADR_SUWAYOMI_USERNAME` и `KADR_SUWAYOMI_PASSWORD` из конфигурации Suwayomi. Прототип принимает loopback-адрес и обслуживает один выбранный источник на процесс. Сохраняйте имя экземпляра постоянным. У тайтла и главы ключи выводятся из локатора расширения, в отличие от внутреннего числового ID. Ссылки изображений ограничены выбранной главой и индексом. Источники проверяются через `GET /api/v1/suwayomi/sources`. Добавьте экспериментальный источник в «Расширениях» и запустите синхронизацию в «Обзоре».

Расширение Pepper&Carrot не поддерживает команду SEARCH. Для прототипа поиск фильтрует результаты доступной страницы POPULAR, а локальный каталог индексирует результат синхронизации. Покрытие помечается SOURCE_LIMIT, поскольку исчерпание популярной выдачи не доказывает полноту общего каталога. Для эксперимента также использован встроенный Local Source с идентификатором 0.

## API и проверка

| API | Действие |
| --- | --- |
| GET /api/v1/library-updates | Порционная лента с `before`, `limit` и `language` |
| POST /api/v1/local-comics и /folder | Импорт главы через multipart или настроенную серверную папку |
| GET /api/v1/suwayomi/sources, GET /api/v1/suwayomi/search | Обнаружение и поиск. Дальше действуют обычные маршруты тайтла, глав и страниц. |
| POST /api/v1/downloads/{id}/queue/{action} | `pause`, `resume`, `prioritize` |
| GET /api/v1/sources/{source}/titles/{title}/bookmarks, POST там же /chapter-actions | Закладки и действия над перечнем выпусков |
| GET и POST /api/v1/library/{entry}/transfer | Предпросмотр и подтверждение копирования |
| GET и POST /api/v1/library-backup, POST /preview | Экспорт, применение и предпросмотр |

- На отдельных базах проверены отсутствие ложных обновлений при первой индексации, один новый выпуск после импорта, смена счётчика при прочтении, смешанный результат пакета, CBZ с именами 2.jpg и 10.jpg, повтор без дублей и перенос с сохранением исходной записи.
- JSON проверен на чистой PostgreSQL и повторно импортирован без дублей. В браузере проверен предпросмотр конфликтов.
- Загрузка Pepper&Carrot восстановилась после перезапуска Spring Boot. Получены все 9 страниц, проверенная ранее первая страница сохранила время записи файла.
- Реальный Pepper&Carrot через Suwayomi вернул 39 глав. Первый и последний JPEG двух выпусков получены через API «Кадра». При остановке Suwayomi запрос поиска вернул 503 SOURCE_UNAVAILABLE. После запуска с тем же каталогом данных ключи тайтла и главы совпали, три повторно проверенные страницы вернули 200 image/jpeg. Кэшируемый Suwayomi MIME image/jpg нормализуется только при корректной сигнатуре JPEG.
- Прошли 25 тестов Maven и production-сборка Angular. Edge проверен с живым API на 390 и 1440 px. Проверены импорт, переход к постраничному виду, восстановление позиции после перезагрузки и в вертикальном режиме, закладка, лента и предпросмотр JSON.
- MangaKakalot и MangaLib через Suwayomi не проверялись. BASIC_AUTH предусмотрен конфигурацией клиента, сквозной прогон выполнен через loopback без авторизации. Проверка восстановления резервной копии касается данных JSON, а не файлов глав.
