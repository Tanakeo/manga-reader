# План подключения источников «Кадра»

## Архитектура и данные

- `MangaSourceRegistry` остаётся реестром зарегистрированных адаптеров. Название и URL сайта берутся из локальных метаданных адаптера. Первым остаётся Pepper&Carrot. Оба списка формируются в порядке `sourceId` без запросов к сайтам.
- `V3__create_connected_sources.sql` создаёт таблицу `connected_sources` с первичным ключом `source_id` и один раз добавляет `peppercarrot`. Наличие строки означает подключение. Flyway применяет миграцию и к базе с V1/V2, и к чистой базе. Повторный запуск приложения читает текущее состояние из PostgreSQL.
- Сервис источников использует `JdbcClient`. Подключение выполняет один `INSERT … ON CONFLICT DO NOTHING`, отключение — один `DELETE` по ключу. Оба запроса предварительно проверяют ID и наличие адаптера в реестре. Повторные и параллельные подключения защищены первичным ключом. Чтение сопоставляет строки таблицы с текущим реестром, поэтому запись об отсутствующем адаптере не попадает в выдачу.

## REST-контракт

| Метод и путь | Ответ |
| --- | --- |
| `GET /api/v1/extensions` | `200 {"items": Extension[]}` со всеми зарегистрированными адаптерами и флагом подключения. |
| `GET /api/v1/sources` | `200 {"items": Source[]}` с подключёнными адаптерами. |
| `PUT /api/v1/sources/{sourceId}` без тела | `200 Source` при первом и повторных запросах. |
| `DELETE /api/v1/sources/{sourceId}` | `204` при первом и повторных запросах. |

`Source = { sourceId: string; sourceName: string; websiteUrl: string | null }`. `Extension` содержит те же поля и `enabled: boolean`. Для синтаксически неверного ID используем существующий `400 VALIDATION_ERROR`, для неизвестного — `404 SOURCE_NOT_FOUND`. Ошибки возвращаются как `application/problem+json`.

## Каталог и совместимость

Каталог сохраняет `q` и `sourceId`. Общий запрос обходит подключённые адаптеры и при пустом списке возвращает `{"items":[]}`. Явный фильтр по известному отключённому адаптеру даёт `409 SOURCE_DISABLED`. Карточки, главы, страницы и библиотека по-прежнему обращаются к зарегистрированным адаптерам напрямую. Отключение меняет только таблицу подключений. Контракт согласован с [заданием для Angular](../../frontend/docs/sources-implementation-prompt.md).

## Проверки

1. Запустить интеграционные тесты через Maven Wrapper с отдельным PostgreSQL 17.12 в Testcontainers. Проверить стартовые данные из миграции, порядок и содержимое списков, отсутствие обращений к внешнему сайту для списков, HTTP-статусы и ошибки, фильтрацию, повторные и параллельные изменения, а также чтение после отключения. Для автоматических проверок глав использовать тестовые ответы источника.
2. Запустить API из `backend/` на существующем томе Compose. Проверить применение V3 поверх V1/V2 и живые запросы, включая страницы Pepper&Carrot и сохранение существующей библиотеки. Перезапустить Spring Boot с отключённым источником и проверить, что состояние сохранилось. По завершении вернуть исходное подключение.
3. Обновить README и сохранить отчёт с фактическими ответами и результатами.
