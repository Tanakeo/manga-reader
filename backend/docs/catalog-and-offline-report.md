# Каталог MangaDex и офлайн-чтение Pepper&Carrot

## Каталог

- `GET /api/v1/sources` объявляет `supportsTags` и `sorts`. `GET /api/v1/sources/{sourceId}/tags` возвращает `{items: Tag[]}`. Карточка тайтла возвращает `tags`. Каждый тег содержит UUID MangaDex, группу `group` и полученные от источника локализации `names`. Angular использует язык интерфейса, затем английский и первое доступное название. [Отчёт Angular](../../frontend/docs/catalog-and-offline-report.md)
- `GET /api/v1/catalog` сохраняет `sourceId` и `q` и принимает до десяти повторяемых `tagId` и `sort`. MangaDex получает условие AND и сортировку вместе с `limit=24`. Доступны `relevance`, `year_asc`, `year_desc` и `latest_chapter_desc`. Последнее значение использует порядок загрузки главы в MangaDex.
- Для фильтра или сортировки требуется `sourceId`. Отключённый источник даёт `409 SOURCE_DISABLED`. Подключённый адаптер без поддержки выбранных параметров даёт `422 CATALOG_OPTIONS_UNSUPPORTED`. Неизвестный тег даёт `422 UNKNOWN_TAG` с `invalidTagIds`. Angular позволяет убрать ошибочные теги и сохранить остальной запрос.
- V5 добавляет `source_tags`, `title_tags` и версию снимка. Каталог и карточка обновляют теги при получении данных MangaDex, сохраняя локальный ID тайтла и его связи с библиотекой. Для ранее сохранённых тайтлов задайте `$env:KADR_TAGS_BACKFILL = 'true'` перед запуском Spring Boot. Заполнение запрашивает до 50 ID за раз. Следующий запуск подберёт строки, у которых ещё нет достоверного снимка. Flyway выполняет только SQL. [Миграции](../src/main/resources/db/migration/)

## Офлайн-чтение

В карточке Pepper&Carrot выберите главу и язык для скачивания. Готовые копии открываются из «Библиотека → Скачанное» по маршруту `/downloads/:downloadId/read`. MangaDex доступен для онлайн-чтения. Запрос на скачивание MangaDex получает `422 DOWNLOAD_UNSUPPORTED_SOURCE`.

| Метод относительно `/api/v1` | Результат |
| --- | --- |
| `POST /downloads` | Создание по `sourceId`, `externalTitleId`, `chapterId` и `language`. Повтор для той же главы и языка возвращает тот же ID. |
| `GET /downloads` | Список `{supported, items}`. Для списка тайтла передаются `sourceId` и `externalTitleId`. |
| `GET /downloads/{id}` | Состояние, число сохранённых и ожидаемых страниц, причина сбоя. |
| `POST /downloads/{id}/retry` | Перевод `FAILED` в `QUEUED` с тем же ID. |
| `DELETE /downloads/{id}` | `202`, пока задача находится в `DELETING`. `204` при повторном запросе после очистки. Активная загрузка даёт `409 DOWNLOAD_IN_PROGRESS`. |
| `GET /downloads/{id}/manifest` | Локальные `title`, `chapter` и `available` с сохранённой атрибуцией и списком готовых копий. |
| `GET /downloads/{id}/pages` | `ChapterPages` с упорядоченными страницами и локальными URL. |
| `GET /downloads/{id}/pages/{index}/image` | Локальный JPEG или GIF. Индексы начинаются с нуля. |

V6 создаёт очередь `chapter_downloads`. V7 связывает записи с тайтлами, добавляет состояние очистки, номер попытки и метаданные страниц в `download_pages`. При первом запуске готовые копии из V6 получают метаданные из локальных файлов. При недостающем или повреждённом файле задача становится `FAILED` и доступна для повтора. После перезапуска прерванная загрузка получает `DOWNLOAD_INTERRUPTED`, а прерванное удаление возобновляется. Готовая глава используется для проверки позиции в библиотеке.

При запуске из `backend/` изображения сохраняются в `./data/downloads`. Задайте `KADR_OFFLINE_DIR`, если нужен другой путь. Для резервной копии нужны PostgreSQL и этот каталог. Для чтения без интернета должны работать локальные Angular, Spring Boot и PostgreSQL. Локальное хранилище рассчитано на один экземпляр бэкенда. Общее S3-совместимое хранилище можно рассмотреть для нескольких хостов. [Сравнение вариантов](catalog-and-offline-plan.md#локальная-папка-или-minio)

## Проверки 16–17 ноября 2026 года

- На живом API получены 77 тегов MangaDex и карточка с девятью тегами. Поиск `prison` с тегами `Reincarnation` и `Long Strip` вернул результаты во всех четырёх сортировках. Неизвестный UUID дал `422 UNKNOWN_TAG`. На отдельной БД пакетное заполнение восстановило девять связей ранее сохранённого тайтла, сохранив его UUID.
- Русский перевод первой главы Pepper&Carrot сохранил пять JPEG-страниц и атрибуцию CC BY 4.0. Повторное создание вернуло тот же ID. После повреждения тестового файла API вернул `503 OFFLINE_FILE_MISSING`. Повтор скачал пять страниц с прежним ID.
- Spring Boot перезапущен с прежней тестовой БД и каталогом изображений при заблокированном внешнем HTTPS. Запрос онлайн-глав вернул `503 SOURCE_UNAVAILABLE`. В Edge открылись первая и последняя страницы. Читалка показала титры и сохранила позицию чтения. Все её запросы были локальными. Каталог и офлайн-читалка проверены при 390 и 1440 px без горизонтальной прокрутки.
- После перезапуска прерванная загрузка перешла в `FAILED`, а ожидавшая удаления запись и остаточные файлы исчезли. Удаление готовой главы также удалило запись и файлы и сохранило запись библиотеки с позицией чтения. Повторное удаление вернуло `204`.
- `.\mvnw.cmd -B -ntp verify` прошла девять тестов. `npm run build` завершилась успешно. [Запуск бэкенда](../README.md#запуск-из-чистого-клона-в-windows-powershell) · [Запуск Angular](../../frontend/README.md#запуск-в-powershell)
