# MangaKakalot и MangaLib

В «Обзор → Источники» доступны `mangakakalot` и `mangalib`. В текущей локальной БД оба включены. В новой БД их можно включить в «Обзор → Расширения» или через `PUT /api/v1/sources/{sourceId}`. Подключение сохраняется при перезапуске.

## Реализация

- **MangaKakalot.** Рабочий домен для каталога — `www.kakamanga.com`. Jsoup разбирает каталог, карточку и HTML главы. Список глав берётся из внутреннего JSON. Читалка получает адреса изображений в исходном порядке и загружает их напрямую. Язык глав — `en`. [Адаптер](../src/main/java/io/github/mangareader/source/mangakakalot/MangaKakalotSource.java)
- **MangaLib.** Публичный каталог и карточки разбираются из структурированных данных сайта. Поиск, список глав и страницы запрашиваются у `api2.mangalib.me`. Относительные пути, включая `//manga/…`, разрешаются на CDN с идентификатором `secondary` из справочника MangaLib. Адаптер выбирает открытые ветки переводов и указывает команду перевода, если она есть. Язык глав — `ru`. [Адаптер](../src/main/java/io/github/mangareader/source/mangalib/MangaLibSource.java) · [Настройки API в LibGroup](https://raw.githubusercontent.com/keiyoushi/extensions-source/main/lib-multisrc/libgroup/src/eu/kanade/tachiyomi/multisrc/libgroup/LibGroup.kt)
- При `403` на запрос поиска оба адаптера ищут совпадения в публичной подборке. Если совпадения там отсутствуют, API возвращает `503 SOURCE_ACCESS_DENIED`. Это поиск по ограниченной выборке. При ошибке одного сайта общий каталог продолжает показывать результаты ответивших источников.
- В обоих адаптерах используются существующий интерфейс `MangaSource`, REST-маршруты и таблица `connected_sources`. Лицензия для конкретной главы из этих ответов неизвестна. Картинки открываются по URL источника. [Условия MangaKakalot](https://www.kakamanga.com/terms-condition) · [Соглашение MangaLib](https://mangalib.org/ru/doc/102--polzovatelskoe-soglasenie)

## Обложки MangaKakalot

Angular загружает обложку через `GET /api/v1/sources/mangakakalot/titles/{titleId}/cover`. Spring Boot использует сохранённый адрес из каталога, а при его отсутствии читает метаданные карточки источника. Запрос к CDN отправляется с адресом сайта в `Referer`, поскольку прямые запросы из «Кадра» получали HTTP 403. Сервер ограничивает адреса доменами адаптера и проверяет тип и сигнатуру ответа. Если изображение недоступно, интерфейс показывает известную обложку того же тайтла из MangaDex или заглушку.

## Первоначальная проверка 17 ноября 2026 года

- Через API «Кадра» MangaKakalot вернул 24 тайтла. По запросу `one piece` нашёлся One Piece. Карточка вернула автора и обложку, список содержал 1384 главы, манифест первой главы — 54 ссылки. CDN вернул `403` на проверенные первое и последнее изображения One Piece, Martial Peak и Kingdom.
- MangaLib вернул 48 тайтлов в каталоге и два совпадения по запросу «человек-бензопила». Карточка открылась с автором и обложкой. Для списка глав API источника вернул `403`, «Кадр» показал ошибку `SOURCE_ACCESS_DENIED` и сохранил ссылку на тайтл у источника.
- В Edge проверен переход «Обзор → каталог → карточка» для обоих источников. У One Piece первая глава открылась в читалке с 54 позициями. На первой и последней позиции браузер показал сообщение об ошибке изображения и действие «Читать в источнике». В карточке MangaLib проверено сообщение о недоступности списка глав.
- `.\mvnw.cmd -B -ntp verify` прошла 11 тестов, включая два теста новых адаптеров. `npm run build` завершилась успешно.
