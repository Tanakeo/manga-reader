# Отчёт о реализации раздела «Обзор»

Проверено 16 ноября 2026 года на Windows. Angular работал на `127.0.0.1:4200`, Spring Boot — на `127.0.0.1:8080`. Для штатных сценариев использованы ответы живого API через dev proxy.

## Реализация

- `/browse` открывает «Источники», `/browse?tab=extensions` — «Расширения». Вкладки доступны мышью и с клавиатуры. Стрелки переключают вкладки, Home и End переходят к первой и последней. После удаления строки фокус с кнопки отключения возвращается на вкладку.
- Экран читает `GET /api/v1/sources` и `GET /api/v1/extensions`. `PUT /api/v1/sources/{sourceId}` подключает адаптер, `DELETE` отключает его из каталога. Пока запрос выполняется, повторное действие для того же ID блокируется. Списки обновляются после подтверждения сервера. При ошибке последнее подтверждённое состояние сохраняется, рядом с источником появляется сообщение и действие снова становится доступным.
- Каталог заполняет фильтр из `GET /api/v1/sources`. Выбор записывается в `/catalog?sourceId=…` и восстанавливается после обновления страницы. Поиск отправляет параметр `q`. Для `SOURCE_DISABLED` доступен сброс фильтра, а при пустом списке подключений каталог предлагает перейти в «Обзор».
- На 390 px основная навигация стоит под логотипом, карточки переносят действия на отдельную строку. Сохранены цвета, типографика, фокус и правило `prefers-reduced-motion`.

## Команды

Из `frontend/` в PowerShell.

```powershell
npm run build
Invoke-RestMethod 'http://127.0.0.1:4200/api/v1/sources'
Invoke-RestMethod 'http://127.0.0.1:4200/api/v1/extensions'
```

## Выполненные проверки

| Сценарий | Фактический результат |
| --- | --- |
| Открытие вкладок и управление клавиатурой | «Источники» открываются по умолчанию. Стрелки переключают вкладки, видимый фокус имеет обводку 3 px. Перезагрузка `?tab=extensions` сохраняет вкладку. |
| Отключение Pepper&Carrot | Список стал пустым и остался пустым после перезагрузки. Прямая ссылка на отфильтрованный каталог показала «Источник отключён». Сброс фильтра показал переход в «Обзор». |
| Обработка отказа при подключении | Временный локальный прокси вернул `503 DATABASE_UNAVAILABLE` на тестовый PUT. В браузере подтверждены состояние «Подключаем…» с `aria-busy="true"`, сообщение об ошибке, возврат кнопки и пустой список источников. Остальные запросы проксировались на действующий сервер. |
| Подключение и сохранение состояния | Живой API принял подключение. Обе вкладки показали новое состояние, перезагрузка сохранила Pepper&Carrot подключённым. Итоговое состояние соответствует исходному. |
| Переход в каталог, поиск и выбор источника | «Открыть каталог» привёл на `/catalog?sourceId=peppercarrot`. Значение сохранилось после обновления и менялось вместе с URL. Поиск по `pepper` нашёл тайтл, запрос без совпадений показал пустой результат. |
| Карточка, читалка и библиотека | Открылась карточка Pepper&Carrot и первая русская глава с пятью страницами. После отключения источника ранее сохранённый тайтл остался доступен из библиотеки, первое изображение загрузилось. |
| Раскладка и сборка | Обе вкладки проверены при 390 × 844 и 1440 × 1024 без горизонтального переполнения. `npm run build` завершилась успешно, начальные JS и CSS — 459,37 кБ до сжатия. |

Отклонений от [плана](sources-implementation-plan.md) по объёму реализации нет. Живой реестр содержит один адаптер, поэтому сценарии с несколькими подключёнными сайтами одновременно в браузере не проверялись. Отдельная эмуляция системной настройки уменьшенного движения не выполнялась.
