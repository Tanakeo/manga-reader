# Magnetic Button

Реализовано 18 ноября 2026 года по утверждённому набору действий.

| Экран | Действие | Область притяжения за границей кнопки | Максимальное целевое смещение |
| --- | --- | --- | --- |
| Тайтл, `/catalog/:sourceId/:externalTitleId` | Начать читать | 24 px | 6 px, содержимое дополнительно 3 px |
| Пустая пользовательская секция, `/library?section=…` | Добавить тайтлы | 24 px | 5 px, содержимое дополнительно 2 px |
| Расширения, `/browse?tab=extensions` | Подключить | 16 px | 4 px, содержимое дополнительно 2 px |

Компонент `Catalog` по маршруту `/catalog` содержит 0 экземпляров директивы. Тайтл использует отдельный компонент `TitlePage`.

## Реализация

`src/app/magnetic-button.ts` содержит общую Angular-директиву. `src/app/magnetic-button.css` подключён из глобальных стилей. Семантический элемент остаётся неподвижным. Двигаются фон через псевдоэлемент и слой `.magnetic-content`. Псевдоэлемент принадлежит той же ссылке или кнопке, поэтому её видимые смещённые края принимают клики. Измеряется неподвижный элемент, без накопления смещения в геометрии.

Пружины используют stiffness / damping 170 / 13 для оболочки, 220 / 15 для содержимого, 400 / 18 для масштаба. При нажатии мышью целевой масштаб равен 0,96. Четыре шага интегрирования за кадр сохраняют устойчивость при пропуске кадров. После затухания цикл останавливается. Смена направления сохраняет текущие позиции и скорости.

Движение включено для событий мыши при наличии точного указателя и hover. Touch, клавиатурный фокус и reduced motion возвращают слои в исходное положение. Стили reduced motion дополнительно убирают transform. Обычные ссылки, Enter, кнопки и фокус используют поведение браузера. Недоступность, ожидание API, отключение эффекта, потеря окна, прокрутка, изменение размеров и уничтожение директивы сбрасывают движение. Обработчики удаляются через AbortController, MutationObserver отключается.

Для подключения источника вход директивы выключается во время запроса и после подтверждённого подключения. Существующие подписи, spinner, сообщение ошибки и блокировка повторного запроса продолжают использовать состояние компонента Browse.

Параметры движения адаптированы из [Magnetic Button](https://designbookmark.com/motion-src/magnetic-button/index.html) и [magnet.js](https://designbookmark.com/motion-src/magnetic-button/magnet.js).

## Выполненные проверки

- `npm run build` прошла. Начальная сборка 499,31 kB, предупреждений бюджета нет.
- Все три действия проверены в браузере с живым Spring Boot при ширине 1440 и 390 px.
- Проверены приближение курсора с двух сторон, быстрый разворот, возврат и неизменность исходного прямоугольника.
- Клик по движущемуся краю «Начать читать» открыл читалку.
- Проверены видимый клавиатурный фокус и Enter у каждого из трёх действий.
- «Добавить тайтлы» открывает диалог. Его закрытие возвращает управление странице.
- При остановленном Spring Boot подключение показало ошибку и вернуло рабочую кнопку. После запуска сервера повторное подключение прошло. «Подключено» имеет aria-disabled=true и data-magnetic=false.
- Проверены переходы между страницами, отсутствие ошибок Angular и горизонтального переполнения на мобильной ширине.
- Отдельная проверка фактического кода директивы с подставленным окружением прошла для затухания и остановки requestAnimationFrame, смены направления, нажатия, reduced motion, touch, грубого указателя, недоступности и удаления обработчиков.

Живая эмуляция reduced motion, touch на физическом устройстве и удержание медленного запроса в состоянии loading в браузере остаются непроверенными. Мобильная проверка использовала изменение ширины окна с указателем мыши.

Тестовая пустая секция удалена. Набор подключённых источников восстановлен и сравнён с исходным. Angular, Spring Boot, контейнер PostgreSQL и Docker Desktop остановлены после проверки.
