# Единые секции библиотеки и Command button

Выполнено 18 ноября 2026 года.

## Секции

Десктопная навигация и мобильный переключатель используют один список. В нём расположены «Все тайтлы», секции статусов, «Скачанное» и пользовательские подборки. При выборе «Скачанного» существующий DownloadsPage отображается внутри библиотеки. Адрес `/library/downloads` перенаправляет в `/library?section=downloads`. Сохранены чтение локальных глав, повтор загрузки и удаление с подтверждением.

В меню у заголовка любой секции, кроме «Все тайтлы», доступно переименование. Миграция V9 добавляет system_key в library_sections и четыре постоянные записи. Название меняется через PATCH существующего API. Ключ секции продолжает определять её содержимое. Пользовательские связи, статусы, заметки и позиции чтения сохраняются.

## Поиск

Command button используется в библиотеке, каталоге и обзоре. Все три страницы импортируют один standalone-компонент из shared/command-search.ts со стилями shared/command-search.css. Исходником служил приложенный React-компонент DesignBookmark Command button, MIT. Подписи, placeholder, доступное имя и запрос задаются через inputs, страница принимает событие search.

Раскрытие использует stiffness 300, damping 28 при исходном bounce 30. Нажатие использует stiffness 520, damping 34 и mass 0,6. Смена слоёв длится 180 ms с cubic-bezier(.23,1,.32,1) и задержкой 60 ms. Значения интегрируются через requestAnimationFrame, цикл останавливается после затухания и удаляется вместе с обработчиками при уничтожении компонента. Reduced motion переключает размеры сразу и отключает blur и масштабирование.

Кнопка раскрывается по клику или Ctrl+K, на Mac используется ⌘K. Поле получает фокус. Enter применяет запрос к названиям RU/EN выбранной секции. В «Скачанном» фильтруются названия тайтлов скачанных глав. Escape сворачивает поле и возвращает фокус кнопке. Клик снаружи и уход из пустого поля сворачивают поиск. Применённый запрос остаётся видимым в свёрнутой кнопке и подписи результатов, сброс доступен в поле. Параметры section и q сохраняются в URL. Смена секции сохраняет запрос.

## Проверки

- Angular production build прошла без предупреждений бюджета.
- Maven verify прошла, 13 тестов без ошибок. Проверены постоянные ключи, переименование встроенной секции, запрет удаления и изменения состава системной секции, уникальность имён и сохранение пользовательских связей.
- Миграция применена к существующей базе. Контрольная сумма всех трёх записей library_entries до и после проверки совпала.
- В браузере проверены десктоп 1440 px и мобильная ширина 390 px, единый список, активная секция и отсутствие горизонтального переполнения.
- Проверены переименование «Читаю», «Скачанного» и пользовательской секции, обновление страницы и сохранение добавленного тайтла.
- Проверены переход по прежнему адресу загрузок, поиск скачанных глав и открытие офлайн-читалки.
- Проверены открытие по клику и Ctrl+K, получение фокуса, Escape, закрытие пустого поля, RU/EN-запросы, отсутствие результатов, сброс, сохранение q при переключении секций, обновление страницы и история браузера.
- Подтверждено отсутствие меню переименования у «Все тайтлы». Ошибок Angular в браузерном журнале нет.

Живой режим reduced motion и физическое сенсорное устройство отдельно не проверялись. Мобильная проверка выполнена изменением ширины браузера.

После подключения общего компонента к каталогу и обзору повторно прошла production-сборка без предупреждений бюджета. В браузере проверены API-поиск каталога с выбранным источником, отсутствие результатов, сброс и перезагрузка. В обзоре проверены поиск по источникам и расширениям, сохранение q при смене вкладки и перезагрузке, отсутствие результатов и сброс. Библиотека повторно проверена с запросом Wind, Escape и Ctrl+K после переходов между страницами. При ширине 390 px поле и выбор источника остаются доступны без горизонтального переполнения. В журнале браузера нет ошибок Angular.

Проверочные названия встроенных секций восстановлены. Созданная для проверки пользовательская секция удалена. Проект оставлен запущенным на http://192.168.1.109:4200/library.
