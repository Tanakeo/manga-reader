# Каталог по источникам и офлайн-чтение «Кадра»

## Каталог

- `GET /api/v1/sources` объявляет `supportsTags` и `sorts`. `GET /api/v1/sources/{sourceId}/tags` отдаёт `{items: [{id, group, names}]}`. Карточка получает собственный массив `tags` отдельно от справочника. Для подписи Angular проверяет активную локаль, английский и первое доступное название по коду языка.
- `GET /api/v1/catalog` принимает `sourceId`, `q`, до десяти повторяемых `tagId` и `sort`. Используются `relevance`, `year_desc`, `year_asc` и `latest_chapter_desc`. MangaDex применяет поиск, условие AND и сортировку до ограничения в 24 результата. Пустое значение `sort` сохраняет прежний порядок. Источники без поддержки тегов показывают обычный поиск.
- Ввод применяется через 220 мс с заменой записи истории. Изменение источника, тега или сортировки создаёт новую запись. Переход в карточку сохраняет нормализованный контекст. Ссылка по тегу открывает каталог источника тайтла. При `UNKNOWN_TAG` можно убрать только неизвестные ID. Список тегов можно загрузить повторно отдельно от каталога.

## Pepper&Carrot

- Локальная копия привязана к источнику, тайтлу, главе и языку. Список берётся из `GET /api/v1/downloads`, при необходимости с параметрами тайтла. `POST /downloads` ставит главу в очередь, `POST /downloads/{id}/retry` повторяет её с тем же ID, `DELETE /downloads/{id}` запускает очистку. Список обновляется, пока сервер сообщает активную загрузку или удаление.
- Раздел `/library/downloads` показывает очередь, прогресс, ошибку, готовность и удаление. Переводы выбираются в карточке главы. Готовый перевод доступен из списка и карточки, даже если список онлайн-глав Pepper&Carrot временно недоступен.
- Офлайн-ссылка ведёт в общий компонент читалки через `/downloads/:downloadId/read`. Прежний `/read/…?downloadId=…` используется, когда библиотека восстанавливает позицию для скачанного перевода. Локальные `GET /api/v1/downloads/{id}/manifest` и `GET /api/v1/downloads/{id}/pages/{index}/image` дают метаданные, страницы и титры. Соседние главы берутся из готовых копий того же перевода. «Сохранить позицию» доступно для тайтла в библиотеке и проверяет страницу по локальной главе.
- Для чтения нужны запущенные Angular, Spring Boot, PostgreSQL и сохранённая папка `backend/data/downloads/`. Для другого пути задайте `KADR_OFFLINE_DIR` в процессе Spring Boot. При переносе нужны и база, и файлы. Команды запуска приведены в [README](../README.md#запуск-в-powershell).

## Выполненные проверки

- На живом MangaDex в браузере применены поиск `prison`, теги `Reincarnation` и `Long Strip` и сортировка по году. Проверены прямой URL, перезагрузка, переход в карточку, ссылка по тегу, возврат с контекстом каталога, «Назад» и «Вперёд». При смене источника запрос сохранился, теги и сортировка очистились. У проверенных тегов был только английский вариант. При смене RU/EN название тайтла менялось, а теги сохраняли английские подписи.
- Валидный UUID отсутствующего тега вызвал `422 UNKNOWN_TAG`. Кнопка убрала только ошибочный ID и сохранила запрос, сортировку и второй тег. Поиск `prison` в Pepper&Carrot показал пустую выдачу со сбросом.
- На ширине 390 и 1440 px каталог и офлайн-читалка помещались без горизонтальной прокрутки. Панель тегов и диалог офлайн-глав открывались клавишей Enter, чекбоксы переключались пробелом, Escape закрывал диалог. У контрола источника видна обводка фокуса 3 px.
- Через карточку скачан русский перевод первой главы Pepper&Carrot. После перезапуска Angular и Spring Boot Spring запускался с HTTP(S)-прокси `127.0.0.1:1`, блокирующим его внешние обращения. Онлайн-список глав вернул `503 SOURCE_UNAVAILABLE`. В новой вкладке офлайн-читалка загрузила все пять изображений по адресам localhost, показала страницу 5 из 5, язык, автора, титры и лицензию. В перечне запросов читалки были локальные манифест, изображения и библиотека. В списке глав был только скачанный перевод.
- Английский перевод той же главы при недоступном источнике получил `FAILED`. Повторный запрос на создание вернул тот же ID. После восстановления сети кнопка «Повторить» перевела запись через очередь в «Скачано» с прежним ID. Удаление тестовой английской копии подтверждено из диалога. Запись и файлы загрузки исчезли, исходная запись библиотеки и русский перевод остались доступны.
- `npm run build` завершилась без предупреждения о размере начального пакета. Начальный JS и CSS занимают 491,15 КБ до сжатия. `.\mvnw.cmd -B -ntp verify` выполнила девять тестов Spring Boot без ошибок.

После приёмки тестовые Angular и Spring Boot остановлены. PostgreSQL работает в существующем контейнере. Русская копия первой главы осталась в «Скачанном», чтобы сценарий можно было повторить после запуска.
