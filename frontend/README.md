# Кадр

Русскоязычная веб-читалка манги и комиксов на Angular 21. Каталог, карточка тайтла, читалка, библиотека и раздел «Обзор» используют действующий REST API Spring Boot.

Чтобы искать и читать через MangaDex, подключите его в «Обзор → Расширения», затем выберите в фильтре каталога. Страницы MangaDex загружаются через существующий Angular dev proxy, а в читалке показывается группа перевода, если источник её указал. [Настройки и ограничения источника](../backend/README.md#mangadex)

## Запуск в PowerShell

Для бэкенда нужны JDK 21 и запущенный Docker Desktop. Для фронтенда подходит Node.js 24 LTS. Для глав и изображений нужен доступ к выбранному источнику.

В первом окне PowerShell выполните команды из корня проекта.

```powershell
Set-Location backend
if (-not (Test-Path -LiteralPath .env)) {
    Copy-Item .env.example .env
}
docker compose up -d --wait postgres
Get-Content -LiteralPath .env | ForEach-Object {
    if ($_ -match '^(POSTGRES_DB|POSTGRES_USER|POSTGRES_PASSWORD|POSTGRES_PORT)=(.*)$') {
        [Environment]::SetEnvironmentVariable($Matches[1], $Matches[2], 'Process')
    }
}
.\mvnw.cmd spring-boot:run
```

Во втором окне PowerShell выполните команды из корня проекта.

```powershell
Set-Location frontend
npm ci
npm start
```

Dev proxy из `proxy.conf.json` перенаправляет `/api/**` на `http://127.0.0.1:8080`. [Открыть Кадр](http://127.0.0.1:4200/catalog)

Для проверки маршрута прокси и сборки выполните команды в `frontend/`.

```powershell
Invoke-RestMethod 'http://127.0.0.1:4200/api/v1/catalog'
npm run build
```

Результат сборки находится в `dist/kadr/browser/`. При размещении сборки веб-сервер должен отдавать `index.html` для маршрутов приложения и проксировать `/api/` на Spring Boot.

## Источники и расширения

Раздел [«Обзор»](http://127.0.0.1:4200/browse) открывается на вкладке «Источники». Во вкладке «Расширения» можно подключить доступный адаптер. Во вкладке «Источники» можно открыть каталог выбранного сайта или отключить его. Ссылка `/catalog?sourceId=peppercarrot` открывает каталог с выбранным фильтром. [План](docs/sources-implementation-plan.md) · [Отчёт и скриншоты](docs/sources-implementation-report.md)

### MangaDex

Подключите MangaDex в «Обзор → Расширения» и откройте его каталог из вкладки «Источники». Каталог показывает обложки целиком в портретной сетке. На карточке тайтла доступны главы и языки из API. В читалке отображаются источник, группа перевода при наличии и ссылка на оригинал главы. [Скриншот каталога](docs/screenshots/mangadex-catalog.jpg)

Обложки и страницы MangaDex загружаются через Spring Boot. Если в библиотеке сохранён прежний адрес обложки с CDN, Angular использует для него новый маршрут. При повторной загрузке страницы сохраняется параметр языка.

В браузере проверены каталог, поиск, карточка и первая английская глава из 17 страниц на примере I Met the Male Lead in Prison. Совместимость со старым URL обложки и повторную загрузку после ошибки проверили через временный тестовый прокси. Angular собрался, четыре существующих теста Spring Boot прошли.

Карточки каталога показывают статус публикации, год и число уникальных глав, доступных в читалке. Счётчик загружается при приближении карточки к видимой области. Переключатель RU/EN управляет названиями тайтлов и подписями сводки. Каталог, карточка, читалка и библиотека получают `titleRu` и `titleEn` из API. При отсутствии перевода отображается исходное название. Словари Transloco содержат подписи сводки. В браузере проверены переключение на обоих языках и сохранение выбора после перезагрузки. [Каталог со сводкой](docs/screenshots/mangadex-catalog-facts.jpg) · [Документация Transloco](https://jsverse.gitbook.io/transloco/core-concepts/language-api)

## Заставка ожидания

Основные экраны показывают случайного персонажа и одну случайную фразу, если запрос занимает дольше 220 мс. Скринридер получает сообщение о том, что именно загружается. Все анимации хранятся локально, имеют прозрачный фон и останавливаются через несколько секунд. При `prefers-reduced-motion` браузер выбирает статичный кадр.

| Персонаж | Источник |
| --- | --- |
| Танцующий персонаж | Предоставленная GIF из `gif/`, фон удалён покадрово |
| Чиби машет рукой и чиби бежит | [Free Animated Character Sprites от Sprited by kndlt](https://kndlt.itch.io/spritedx-character-sprites), CC0 1.0 |
| Мичона подпрыгивает | [Anime Girl от Hordana](https://lpc.opengameart.org/content/anime-girl), CC0 1.0 |

Чтобы добавить персонажа, положите анимацию и статичный кадр в `public/loading/` и добавьте пару путей в `loadingCharacters` в `src/app/common.ts`.

## Теги, фильтры и скачанные главы

В каталоге MangaDex можно выбрать до десяти тегов. В выдачу входят тайтлы со всеми выбранными тегами. Поиск выполняется в выбранном источнике, а MangaDex сортирует результаты до ограничения выдачи. Выбор сохраняется в ссылке и истории браузера. Плашки под описанием тайтла открывают его источник с фильтром по тегу. Переключатель RU/EN меняет подписи, для которых API отдаёт перевод.

На карточке Pepper&Carrot нажмите «Скачать главу» и выберите язык. В «Библиотека → Скачанное» можно открыть готовый перевод, повторить загрузку или удалить локальную копию. Angular, Spring Boot и PostgreSQL должны работать при чтении без внешнего интернета. Изображения лежат в `backend/data/downloads/`. Путь можно задать переменной `KADR_OFFLINE_DIR`.

## Фактические проверки

Проверено 16 ноября 2026 года в браузере Codex на Windows. PostgreSQL уже работал в существующем Docker Compose со статусом `healthy`, Spring Boot слушал `127.0.0.1:8080`. Использовались Node.js 24.14.1 и Angular 21.2.

- Живой API вернул Pepper&Carrot, 39 глав и 5 страниц первого русского эпизода в порядке индексов `0–4`. Поиск и фильтр по источнику дали ожидаемые результаты, пустой поиск сбросился. Браузер показал страницы, счётчик при прокрутке, список глав и переход к соседней главе.
- В браузере пройден сценарий «каталог → тайтл → русский эпизод → чтение → добавление → обновление вкладки → редактирование → удаление». После `PATCH` видны статус, заметка и позиция из ответа сервера. «Продолжить чтение» открывает сохранённую страницу. Проверены отмена диалога по Escape и подтверждение удаления. Тестовая запись удалена, библиотека вернулась к исходному пустому состоянию.
- Повторное добавление в параллельно открытой вкладке получило `409 DUPLICATE_LIBRARY_ENTRY`. Проверены [успешное состояние](docs/screenshots/add-success-390.jpg) и [ошибка добавления](docs/screenshots/add-error-390.jpg). `PATCH` с номером страницы 999 отклонён, сообщение отображается рядом с полем, прежний статус сохраняется. После исправления на страницу 3 запрос прошёл.
- Для 39-й главы API вернул `422 LANGUAGE_UNAVAILABLE` по-русски. Читалка показала ссылку на английский вариант, который открылся. Запрос без статуса вернул `400 VALIDATION_ERROR` с полем `status`.
- На временных проверочных ответах выполнены тесты длинных русских заголовков, адаптивной сетки с двумя тайтлами, `503 SOURCE_UNAVAILABLE` и ошибок обложки и страницы. Измерена ширина документа, проверены клавиатурный фокус и контраст. Подробности в [отчёте визуальной сверки](design-qa.md). Impeccable в доступных навыках и командах отсутствовал.
- `npm run build` прошла. Начальные JS и CSS составили около 438 кБ до сжатия. В проверенных пользовательских сценариях браузерный журнал Angular остался без ошибок.

## Особенности контракта

- `GET /api/v1/sources` возвращает подключённые источники для фильтра каталога. `GET /api/v1/extensions` показывает зарегистрированные адаптеры и состояние подключения. Отключение источника убирает его из каталога, доступ к ранее сохранённым тайтлам остаётся.
- `GET …/chapters` отдаёт `title` и `languages`, а локализованное название приходит в `GET …/pages?language=…`. Поэтому в списке показаны названия из API, в читалке — название выбранного перевода.
- У `Page` доступны `index` и `imageUrl`. Для заранее вычисленного размера нужны `width` и `height`. Страницы отображаются с исходными пропорциями, позиция при продолжении чтения выставляется после загрузки предшествующих изображений.
- Бэкенд предоставляет единую библиотеку. Раздельные библиотеки требуют учётных записей и серверного определения владельца записи.
